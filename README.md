# LeetCode

LeetCode solutions in C, one folder per problem under `problems/`.

Each folder has `solution.c` (what gets submitted) and `test.c` (the examples, as asserts).

```sh
make        # build and test everything
make 0001   # just one problem
```

Open the folder in the dev container (VS Code: "Reopen in Container") for gcc, gdb and make.
